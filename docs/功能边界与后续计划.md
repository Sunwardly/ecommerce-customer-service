# 演示功能边界

本仓库的可验收范围是文字对话、访客会话隔离、只读演示商品/订单/物流查询和订单详情介绍。
以下内容明确不属于已交付功能，不能据此宣称项目可以直接用于生产客服。

| 能力 | 当前行为 | 后续验收条件 |
| --- | --- | --- |
| FAQ / RAG | 返回未检索到信息的占位结果，无向量数据库 | 确定授权知识数据、检索接口、引用规则和失败行为，并添加回归 |
| 相似推荐 | 流程演示，不是正式推荐服务 | 接入实际候选商品与排序，验证权限范围和空结果 |
| 退款 / 转人工 | 只演示流程，站点业务网关拒绝写操作 | 另行设计认证授权、确认、幂等、人工通道与审计，不得擅自开放现有写接口 |
| 数字人 | 代码和素材存在，SDK / 云资源未完成验收 | 按用户要求暂不开发，后续单独验证 |
| 生产部署 | 当前本地与隧道演示，HTTP | 独立部署方案、HTTPS、限流、备份、监控及安全验收 |
| 数据库升级 | 初始化只创建缺失表，不修改既有表 | 结构变化必须另写经审查的迁移与恢复方案 |

这些是明确记录的未完成能力，代码清理或补充 CI 不代表它们已经实现。
