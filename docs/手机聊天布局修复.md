# 手机聊天布局与输入聚焦修复

2026-10-09。修改 `customer-service-frontend/src/App.vue`，未修改后端、数字人业务逻辑或历史数据。

手机端取消大标题和常驻控制/数字人栏，使用紧凑客服顶部栏。订单/商品列表通过顶部按钮打开，面板支持刷新、返回聊天；发送对象后自动返回聊天。桌面布局保留。

手机页面锁定在实际可视视口，只有消息列表和对象列表内部滚动。使用 visualViewport 高度及 offsetTop 同步容器，按动画帧合并视口事件；移除聚焦时的整页 scrollIntoView，不再在用户查看历史时无条件滚到底。输入字号至少 16px，避免 iOS 的小字号自动放大，保留底部安全区。

验证：前端构建通过；390×844 浏览器视口消息区约 718px；聚焦输入框后页面 scrollY=0；缩小至 390×430 时消息区约 304px，输入区域底部 429px，仍位于可视高度内。订单面板打开、返回、发送后自动关闭通过；恢复桌面视口后手机按钮隐藏。

截图：`mobile-chat-layout.png`、`mobile-chat-reduced-viewport.png`。

浏览器缩小视口用于验证布局适配，不能替代 iPhone 微信真实软键盘测试；需要在原手机刷新页面后确认键盘弹出/收起与微信浏览器栏变化的效果。
