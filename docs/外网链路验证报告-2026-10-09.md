# 外网链路验证与初步测速

日期：2026-10-09（北京时间）。本轮目标：验证已有本地服务与公网入口，建立性能基线；不实施 UI 改版。

## 结论

已恢复本地与外网文字客服链路。用户确认关闭手机 Wi-Fi、使用移动数据后能够打开网站并聊天。

入口：http://12lh9932zk192.vicp.fun/

最初无法访问的直接原因是服务未启动：本机 5174、18082 没有监听，VMware 没有运行中的虚拟机。公网返回 HTTP 200，但内容为花生壳“内部网站连接失败”，提示目标 127.0.0.1:5174 不可达，并非项目首页。

经用户确认，192.168.200.120 的业务环境属于 260901（CentOS 7）。启动该虚拟机后，业务中台自动恢复。

## 初步性能基线

以下为本机经公网域名进行的请求，不是手机端浏览器测速。本机存在 FlClash 虚拟网络，结果包含本机网络路径的影响。

| 请求 | 三次耗时（秒） | 中位数（秒） |
| --- | --- | --- |
| 本地 HTML | 0.020 / 0.003 / 0.002 | 0.003 |
| 公网 HTML | 0.258 / 0.057 / 0.061 | 0.061 |
| 公网主脚本 | 0.344 / 0.080 / 0.100 | 0.100 |
| 公网样式 | 0.274 / 0.065 / 0.066 | 0.066 |

连续请求存在连接复用，因此中位数不代表冷启动。HTML、脚本和样式下载耗时也不等于完整首屏可操作时间；“首次可操作 5 秒以内”尚未验收。

一次 curl 压缩请求：主脚本实际传输 35,534 字节，耗时 0.318 秒；样式实际传输 5,943 字节，耗时 0.119 秒。解压后分别为 92,756 和 29,309 字节。GET 响应已有 Content-Encoding: gzip，不需要把“开启压缩”当成尚未实现的优化。

静态资源返回 Cache-Control: no-cache，存在 ETag、Last-Modified；这允许缓存但要求重新验证，不等于完全不缓存。

## 已确认但尚未实施的产品要求

- 受邀演示、零新增费用；入口访问口令、服务端验证的独立访客聊天身份。
- 聊天身份与演示业务身份分开；服务端限制演示数据与真实业务写接口。
- “新对话”创建新的对话标识与任务上下文，刷新恢复当前对话；旧数据保留。
- 数字人仅明确点击后启用；单访客独占，释放验证归属；无法保证隔离则不向外网开放。
- 占位能力明确标注，不宣称真实提交退款或已连接人工坐席。
- UI 保持暗色，采用石墨蓝紫（背景 #101218、主色 #818CF8、辅助 #7DD3FC）；先出桌面和手机预览，认可后实现。

当前口令、身份隔离和写接口限制均未实现。“公网链路可用”不代表已完成受邀演示的访问控制验收。
