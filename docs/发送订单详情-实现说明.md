# 发送订单后介绍当前详情

2026-10-09 实现。数字人及前端界面未修改。

点击“发送订单”后，后端根据订单 ID 查询受限的演示业务接口，直接回复订单号、状态及状态说明、商品数量/单价、总金额、下单时间，以及物流状态、公司、运单号和最新轨迹。不存在物流记录时显示“暂无物流记录”，查询失败时明确提示，不根据前端卡片属性或 LLM 编造详情。

此前对象消息在没有业务流程时进入“缺少咨询对象”的澄清回复，本次在订单对象处理分支增加详情说明。商品对象行为不变；已有业务流程收集订单时先介绍详情，再继续流程。订单详情属于发送当时的查询结果，保存在聊天历史中；再次发送订单会重新查询，历史不会自动更新。

涉及文件：

- `customer-service-backend/construction_service/services/order_overview_service.py`：读取并组织订单及物流详情，处理越界、缺失和失败。
- `customer-service-backend/construction_service/engine/dialogue_engine.py`：订单对象分支接入详情，保留任务推进和历史提交。
- `customer-service-backend/tests/test_order_overview.py`：详情、最新物流、无物流、服务失败、越界、任务推进、历史和商品回归。

30 项后端回归通过。公网真实 API 验证待发货、运输中、待揽收、已完成和已取消五种订单，状态和金额与详情接口一致，篡改客户端属性不影响回复，越界订单被拒绝。浏览器发送订单后收到详情，刷新后仍能恢复；截图 `order-overview-browser.png`。
